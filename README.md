# Comic Tracker for Android

Comic Tracker packaged as an Android app with Capacitor. Every push to `main` builds a signed APK on GitHub Actions and publishes it as a release.

Download: https://github.com/Al3nafk/comic-tracker-android/releases/latest/download/ComicTracker.apk

`www/` is generated by `mobile/build.ps1` in the Comic Tracker folder on the PC; don't edit it here.
